# CS-330-Portfolio
CS-330 Module 8 Portfolio

How do I approach designing software?
-What new design skills has your work on the project helped you to craft?
-What design process did you follow for your project work?
-How could tactics from your design approach be applied in future work?
--------------------
Working on this 3D scene has helped me learn how to plan and design more complex objects by combining basic shapes, textures, and lighting. I started with the idea of creating a pharmacy pill-counting scene because it was something familiar to me. I then broke the scene into individual objects, such as the pills, spatula, tray, and bottle, and worked on creating each one before bringing everything together. In future projects, I can use this same approach by planning out the main parts of a program first and breaking larger problems into smaller, more manageable tasks.


How do I approach developing programs?
-What new development strategies did you use while working on your 3D scene?
-How did iteration factor into your development?
-How has your approach to developing code evolved throughout the milestones, which led you to the project’s completion?
--------------------
Throughout this project, I learned the importance of testing my code and making changes as I went. I used C++ and OpenGL to create the objects, apply textures, set up lighting, and implement camera controls. I had to troubleshoot problems and make adjustments to get the objects looking and working the way I wanted. As I progressed through the milestones, I became more comfortable working the existing code and adding in new features. Instead of trying to complete everything at once, I found it helpful to work on one part at a time and test it before moving on. This helped me build the scene gradually and understand how the different parts of the code worked together.
